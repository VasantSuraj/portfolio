01 · Ask

Ask Claude for a CMO analysis.

Paste a YouTube link, or a podcast episode's audio link, into Claude and ask for a CMO analysis. The tool lives on an MCP server, so any assistant connected to it can do the same.

02 · A number back

A job number, straight away.

The link is tidied, with tracking bits removed, and sorted as video or audio. The reply comes at once: a job number, "processing", and a note to come back in about 90 seconds. The work carries on behind it.

job number
03 · Two ways in

Video skips a step.

A YouTube link's captions come back ready-made. An audio link goes through CloudConvert first: mono, 16 kHz, 32 kbps, small enough for the transcriber to take a long episode in one go.

video: captionsaudio: compressed
04 · The words

The whole episode, word for word.

Groq runs Whisper (large-v3 Turbo) over the compressed audio and returns every word as plain text.

05 · The brief

Boxed for a marketing leader.

Claude reads the transcript as an analyst briefing a CMO or head of demand gen, using only what was said: a summary, key topics and themes, up to six verbatim quotes, five to seven learnings with what to do about each, every company mentioned, three posts and two or three blog ideas.

nothing invented
06 · Filed

Two files in Drive.

The transcript, headed with the show, episode, link and date, is saved as a text file. The brief is saved as JSON under its job number. Both go into the same Google Drive folder.

07 · Pick up

Come back with the number.

The assistant asks for the result with its job number. Until the brief is in Drive the answer is "not ready yet, try again in about 30 seconds". Then the brief comes back into the chat.

01Problem

"You should listen to this episode" costs an hour.

Good podcasts are full of tactics, numbers and names a marketing team could use, but they arrive as an hour of audio at a time. Most get saved for later and never heard, and the few minutes that mattered in each one are lost.

02Running it

  1. 01

    Connect once

    Add the MCP server to your AI assistant. It brings two tools: one starts a job, the other collects the result.

  2. 02

    Ask

    Paste a YouTube link or an episode's audio link (.mp3) into Claude and ask for a CMO analysis. Claude calls the first tool with the link.

  3. 03

    Get a number

    The reply is immediate: a job number and "processing", with a note to check back in about 90 seconds.

  4. 04

    Let it wait

    The assistant asks for the result with the job number. "Not ready yet" means it asks again about 30 seconds later.

  5. 05

    Read the brief

    When it's done, the brief comes back into the chat. The brief and the transcript are both in the Drive folder, to keep or reuse.

03Flow

  1. 01

    The link arrives

    The assistant's tool call posts the link to the main workflow.

    MCP Server Trigger · Webhook
  2. 02

    Tidy, sort, answer

    Share and tracking parameters are stripped, the link is sorted as YouTube or audio, and a job number is made from the time and a random suffix. The caller gets the job number straight away; the rest runs on.

    Code · Respond to Webhook · Switch
  3. 03

    Video: fetch the captions

    For a YouTube link, a transcript API returns the video's captions in segments, which are joined into one text.

    HTTP Request · Code
  4. 04

    Audio: compress, then transcribe

    CloudConvert imports the audio from its link and re-encodes it as a mono, 16 kHz, 32 kbps MP3. The workflow waits for the job, downloads the file and sends it to Groq's Whisper (large-v3 Turbo).

    HTTP Request × 4 · CloudConvert · Groq
  5. 05

    Write the brief

    Claude reads the full transcript and returns one JSON object with fixed keys, written for a B2B CMO or head of demand gen.

    Claude
  6. 06

    File both

    The brief is saved as job number.json; the transcript, with a header for the show, episode, link and date, as a text file. Both go to one Google Drive folder.

    Code × 2 · Convert to File × 2 · Google Drive × 2
  7. 07

    Collect it

    A second workflow answers the result tool: it looks for the job's file in the folder. Found, it reads the brief and returns it with "done"; not found, it returns "processing" and "try again in about 30 seconds".

    Webhook · Google Drive × 2 · If · Extract from File · Code · Respond

04The brief

Every brief has the same keys, so it reads the same way each time and other tools can use it. Claude works only from the transcript: nothing is invented, and anything unclear is marked "Unknown". The transcript has no speaker labels, so the host and guests are inferred from the conversation.

05If something fails

  • Start hereThe Executions tab of the main workflow in n8n shows which step stopped and why.
  • "Not ready" for much longer than usualThe main run stopped before it saved the brief, so there's nothing to collect. The usual causes: the audio link couldn't be fetched, or the conversion failed.
  • The brief says "no transcript"There was nothing to work from: the video has no captions, or the audio didn't transcribe.
  • The result is marked as unreadableThe brief came back cut off or malformed. Run the episode again.
  • A feed link instead of an episodeUse the link to one episode's audio file. A podcast's RSS feed is the whole show, not an episode.

~90 suntil the assistant first checks back
5–7learnings, each with what to do about it

An hour of audio becomes a structured brief in a few minutes, with no one listening. The hour goes into deciding what to do, not into hearing it first.

07Operating it

  • The assistant does the waitingIt holds the job number and checks back on its own. There's nothing to watch.
  • Video is the quick wayA YouTube link skips the download, conversion and transcription, so its brief is usually back sooner.
  • Everything is keptBriefs are named by job number and transcripts by show and episode, side by side in one folder, ready to search or reuse.
  • Built for marketing leadersThe brief is written for someone running B2B marketing or demand gen: tactics, numbers and tools over general takeaways.
