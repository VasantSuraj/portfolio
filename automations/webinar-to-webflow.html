Webinar to Webflow

YouTube link in, labelled transcript and CMS recap page out.

Read the runbook
01 · The link

A webinar link goes in.

From an internal web app, a YouTube link goes to the transcript webhook. Supadata fetches the video's title and its timestamped captions, checking every 8 seconds until they're ready.

02 · Blocks

Captions become readable blocks.

The caption cues are merged into blocks of up to 18 seconds and split wherever the captions mark a new speaker with >>, so a handover never lands mid-sentence.

03 · Speakers

The model names the speakers, never the words.

Gemini returns only where the speaker changes and who it is. Code applies the labels and restores any marked handover the model missed, so nothing can be paraphrased or dropped.

hostguest
04 · Cleanup

Cleaned, but never shortened.

Gemini Flash Lite strips fillers, typos and false starts in 16k-character batches. A batch that shrinks below 55% or stops matching what was said is thrown out, and the original words stay.

batch keptreverted to the original
05 · Transcript

The transcript lands in Google Docs.

Timestamps, speaker names and a confidence header, saved as a Google Doc with SRT and JSON copies. The app gets the link back two to four minutes after the YouTube link went in.

06 · Conversation

The doc becomes a Conversation page.

From the transcript, Gemini writes the recap page as HTML: an intro, the guest's bio, 6 to 10 themed sections and a conclusion. Code cleans the HTML, rescues output cut off at the token limit, and flags anything the reviewer should check.

07 · Webflow CMS

Approved, then pushed into Webflow.

Once a person approves it, the page is mapped onto the Conversations collection's fields (slug, read time, guest, video link and thumbnail) and created as a CMS item. If the high-res thumbnail is rejected, the standard one goes in instead.

A one-hour webinar becomes a named transcript and a draft recap page within minutes.

A person approves every step. The words are never rewritten.

01Problem

A one-hour webinar took a day to become a recap page.

Get the transcript, work out who said what, strip the filler, write a detailed summary, then rebuild it as HTML in Webflow with the guest bio, read time and thumbnail. Recaps lagged the event by weeks, or never got written.

02Flow

  1. 01

    Transcript request

    Code checks the YouTube URL. Supadata returns the video title and timestamped caption cues, polled every 8 seconds until the job is ready.

    Webhook · Supadata
  2. 02

    Readable blocks

    Cues are merged into blocks of up to 18 seconds and split on the captions' >> speaker markers, so handovers never land mid-sentence.

    Code
  3. 03

    Speakers by change point

    Gemini 3.5 Flash (JSON output) returns only the points where the speaker changes and the names, never a rewritten transcript. Code applies the labels and repairs any marked boundary the model missed.

    Gemini · Code
  4. 04

    Guarded cleanup

    Gemini 3.5 Flash Lite cleans each 16k-character batch (typos, fillers, false starts) under strict rules. Code rejects any batch that shrinks below 55% or no longer matches the original turn, and keeps the raw wording.

    Gemini · Code
  5. 05

    The transcript

    Assembled with timestamps, a confidence header, and SRT and JSON copies. Google Docs creates the doc; the webhook returns the link and text to the app.

    Code · Google Docs
  6. 06

    Recap request

    Gemini 3.5 Flash (JSON output) writes the recap page as HTML: intro, guest bio, 6–10 themed sections of specific bullets, conclusion. Code sanitises the HTML, recovers partial output if the token limit is hit, and returns warnings for the reviewer.

    Webhook · Gemini · Code
  7. 07

    Publish request

    Once approved in the app, Code maps the recap onto the CMS fields (slug, read time, guest details, video link, YouTube thumbnail) and Webflow creates the item in the Conversations collection.

    Webhook · Webflow CMS

03Keeping the words

  • Change points, not textThe model only says where a new speaker starts and who they are. The words themselves never pass through it for labelling, so they can't be paraphrased or dropped.
  • Boundaries repairedIf the captions marked a handover the model missed, code restores it.
  • Shrink ratioA cleaned batch shorter than 55% of the original is treated as a summary and thrown away.
  • Word overlapA cleaned batch that no longer matches the original turn is also thrown away. Either way, the raw wording is kept.

04Error handling

  • Thumbnail rejectedIf Webflow rejects the high-res YouTube thumbnail, code falls back to the standard one and retries the create.
  • Model hiccupsEvery Gemini call retries 3 times.
  • Cleanup never blocksA failed cleanup batch keeps its original text; the transcript still completes.
  • Cut-off recapIf the recap hits the token limit, the partial HTML is recovered and the reviewer is warned.

05Outcome

2–4 minfor a named, cleaned transcript (longer past an hour)
55%the shrink floor: below it, the original words are kept
3requests from the app, each approved by a person

A draft recap page follows the transcript within a few minutes and lands in Webflow as a ready CMS item: fields filled, thumbnail set, slug generated. The model labels and cleans, but it can never rewrite or shorten what was said.
