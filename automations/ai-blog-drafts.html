AI Blog Drafts

Flag a sheet row, get a 3,000-word draft in Google Docs.

Read the runbook
01 · The sheet

Every blog starts as a row.

A Google Sheet holds one row per blog: the title, a primary keyword, secondary keywords and a link to the SEO brief. The last column, the article link, stays empty for now.

02 · Flag the batch

Flag the whole batch in one go.

Setting Run Action to YES starts a blog. Type the YESes in a spare column, then paste them in together. Typed one by one, they start some drafts before the other rows are ready.

YES starts the run
03 · The voice

It writes in the writer's own voice.

Each writer has a style file: how they open, how they argue, the words they reach for. Claude reads it alongside the brief, so the same automation can write for anyone with a style file.

04 · One at a time

Each draft grows from the brief.

The workflow takes the flagged rows in turn. Claude outlines from the brief, writes each section, and fills it out to a full 3,000 to 4,000 words. Leave queued rows alone until it finishes.

05 · Delivered

Saved, linked, announced.

The draft is saved as a Google Doc, the row's article link fills itself in, and a message lands in the team's Slack channel. Open the Doc, review it, hand it to the editor.

06 · When one fails

A failed run says where.

The usual cause is a brief that hasn't been shared. The run log in n8n shows which step stopped and why. Share the brief, then run that row again.

01Problem

A first draft took hours of writing per post.

Every post already had a title, keywords and an SEO brief before anyone wrote a word. Turning that into a full first draft, in a voice that sounds like the writer, was the slow part.

04Writers' voices

  • A style file per writerHow they open a post, how they argue, the words and rhythm they use. The workflow is the same for everyone; only the style file changes.
  • Adding a writerGive the workflow a new writer's style file and a sheet of their own. Their drafts come out sounding like them.

05Guardrails

  • Fill rows firstComplete Title, keywords and Brief Document for every row in the batch before touching Run Action.
  • Paste the YESes in one goType them in a spare column lined up with the rows, then cut and paste them into Run Action together. Typing them one by one fires the run before the other rows are ready.
  • Hands off queued rowsDon't edit rows while the batch is running. Mid-run edits can confuse the loop and fail or overwrite a draft.
  • Share every briefA brief the workflow can't open is the most common failure. Check every link before the run.

06Outcome

1Google Doc per flagged row, linked back in the sheet
3–4kwords per draft, in the writer's voice
6columns in the sheet, and the workflow fills the last one

A full draft lands in Google Docs minutes after a row is flagged. The writer's time goes into reviewing and sharpening, not into the first pass.

07Operating it

  • It didn't startIf the sheet trigger doesn't fire, open the workflow in n8n and run it manually. When the workflow is active, you never need to.
  • A draft didn't arriveOpen the Executions tab in n8n: it shows which step stopped and why. Fix the cause, usually the brief's sharing, and set that row to YES again.
  • Knowing it's doneThe article link appears in the row and a Slack message arrives. Either one means the Doc is ready to review.
